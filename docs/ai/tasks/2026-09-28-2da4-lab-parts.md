# 2DA4 Separate Lab Parts

## Scope

Replace each combined two-week 2DA4 lab row with separate, independently checkable `Part 1` and
`Part 2` rows on the two attended weeks. Apply the change to Labs 1–5 while preserving assignments,
lectures, Midterm 1, grading, and other courses.

## Completion Compatibility

Part 1 keeps each historical `lab-N` ID, so an existing completed lab row remains completed as
Part 1. Part 2 uses a new `lab-N-part-2` ID and starts incomplete. The existing 2DA4 task storage
key remains unchanged.
